# Mitsuki Shibagaki — researcher website

柴垣光希さんの研究者ホームページ試作です。GitHub Pagesでそのまま公開できる静的サイトとして作成しています。研究者情報を掲載するメインページと、独立した趣味ページで構成しています。

## Preview

`index.html` をブラウザで開くか、ローカルHTTPサーバーでこのディレクトリを配信してください。

```powershell
python -m http.server 8000
```

その後、`http://localhost:8000` を開きます。

## Before publishing

- プロフィール本文、所属、研究テーマ、受賞歴を本人確認する
- 趣味ページに掲載する内容やリンクを必要に応じて更新する
- 必要なら本人が使用権を持つプロフィール写真と連絡先を追加する
- GitHubのリポジトリ名・公開URLに合わせて、`index.html` のOG画像URLを絶対URLに変更する
- GitHubのリポジトリ設定で **Settings → Pages → Deploy from a branch** を選び、`main` / `(root)` を指定する
